# Procurement Screening Package

Use this procedural package when the professional task is to determine whether a supplier is eligible to transact based on sanctions, restricted-party, or legal-entity screening evidence.

Do not use it merely for supplier performance scoring or contract-clause comparison.

Required deeper resources before execution:

1. `architect/references/benchmark-fixtures/round2/sanctions-evidence-procedure.md`
2. `architect/references/benchmark-fixtures/round2/supplier-identity-normalization.md`

Both dependencies are required: screening evidence is invalid if entity identity has not first been normalized.
