# Sanctions Evidence Procedure

Execution dependency for Procurement Screening Package.

Required evidence sequence:

1. confirm normalized legal entity identity;
2. query the authoritative restricted-party source;
3. preserve source/version/time and match rationale;
4. distinguish exact match, probable match, and no match;
5. route ambiguous matches for professional review rather than silently clearing them.

A screening decision is not valid from name similarity alone.
