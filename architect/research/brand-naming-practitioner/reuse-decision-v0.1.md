## Architecture alternatives

1. REUSE one existing internal core — REJECT.
2. ADAPT external naming skill — REJECT because local qualification/provenance/evidence gaps are material.
3. EXTEND Social Content Creative — REJECT; naming changes professional responsibility, not a bounded creative-execution extension.
4. EXTEND Visual Design / Art Direction — REJECT; lexical/linguistic naming craft is not a visual-design delta.
5. BUILD NEW top-level naming core — REJECT for now as excessive architecture.
6. **BUILD NEW reusable Brand Naming capability package** — SELECTED.

## Why BUILD NEW is now evidence-backed

The applied repository originally classified naming as CAPABILITY / NO SEND. Its reopen trigger required repeated materially different naming work and evidence of a stable competency boundary.

That trigger is now met:
- Spline/automotive brand work already separated naming from visual identity;
- Personal Brand Growth System now requires naming for a personal identity/social handle;
- professional practice and empirical/legal sources show recurring invariants that survive both contexts;
- no current internal core owns those invariants;
- external candidates are not eligible for trusted reuse.

Therefore upstream BUILD NEW applies to the **capability artifact**, not to a new top-level core/agent.
