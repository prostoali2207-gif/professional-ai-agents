## Compatibility result

None of the qualified cores matches the target responsibility/output boundary, training-science competencies, physiological population assumptions, exercise prescription judgment, safety interface, training-history state, or practical evaluation construct.

The generic Agent Architect methodology, runtime-state methodology and evaluation infrastructure are reusable **engineering methodology**, not a professional-core transfer.

## Formal decision

**BUILD NEW**

Build a new target-specific applied professional model and skill. Do **not** create a new generic pack merely to populate the library.

## Rejected alternatives

### REUSE / ADAPT existing qualified core — REJECT

A marketing, content, sales, measurement or video core does not own resistance-training decisions. Vocabulary overlap such as "experimentation", "measurement", "fatigue" or "optimization" is not professional compatibility.

### EXTEND Growth Experimentation & Measurement — REJECT

Longitudinal training adjustment uses evidence and trends, but the critical construct is biological training prescription and exercise-specific judgment, not causal experiment governance. Extending the analytics core would import the wrong responsibility boundary and evaluation construct.

### FORK an existing core — REJECT

No existing core is close enough for a fork to preserve meaningful invariants. Forking would add false provenance.

### External fitness skill import — REJECT as trusted reuse

Public prompts/programs can be discovery material only. No external artifact has been shown to meet this repository's provenance, evidence, professional-construct and qualification gates. Current design therefore builds from authoritative/primary evidence rather than importing a role prompt.

## Lifecycle/resource trade-off

BUILD NEW costs more initial profession/evidence/evaluation work but has lower long-term coupling and false-inheritance risk than adapting an unrelated qualified core. The scope is intentionally narrow: healthy-adult hypertrophy and exercise-specific strength programming.
