## Formal decision

**BUILD NEW** applied professional capability.

Reason:
1. no qualified nutrition/sports-nutrition core exists;
2. title similarity cannot substitute for professional compatibility;
3. inherited qualification from analytics/research would falsely imply nutrition competence;
4. the target requires health-relevant evidence and escalation boundaries absent from current cores.

## What may still be reused

Reuse is limited to repository **methodology/infrastructure patterns**, not professional claims:
- source provenance and uncertainty conventions;
- runtime-state/memory methodology;
- evaluation integrity and stop-loss rules;
- deterministic arithmetic/checking where applicable.

These are cross-cutting Architect mechanisms and do not transfer a nutrition qualification.

## Alternatives rejected

- **ADAPT growth-experimentation-measurement**: rejected because the delta would contain almost the entire target profession.
- **EXTEND an existing core**: rejected because no existing core owns the professional responsibility boundary.
- **FORK a marketing/research core**: rejected because shared internals would create misleading provenance and unnecessary coupling.
- **Build a new generic health framework**: rejected; the task needs a narrow applied skill, not new generic infrastructure.

## Required regressions

Because no professional core is inherited, there is no inherited domain PASS to regress. The new applied artifact must independently cover:
- energy/protein/macro decisioning;
- low-appetite adaptations;
- measurement uncertainty;
- supplements;
- health escalation;
- stateful adjustments;
- practical and adversarial cases.
