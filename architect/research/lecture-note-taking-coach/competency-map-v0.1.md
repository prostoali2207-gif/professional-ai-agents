# Lecture Note-Taking Coach — competency map v0.1

Status: PRE-SKILL MODEL

| Competency | Class | Observable capability | Failure mode | Evaluation |
|---|---|---|---|---|
| Diagnose note behavior | CORE | identifies over-transcription, under-capture, flat structure, missing relations | generic "write less" advice | critique real note sample |
| Information selection | CORE | separates thesis/core point from support/example/filler | copies everything or omits key claims | noisy lecture fixture |
| Hierarchy/organization | CORE | captures headings, subpoints, relations, sequence | flat bullet dump | hierarchical lecture |
| Compression/paraphrase | CORE | shortens while preserving reconstructability | semantic loss or cosmetic shortening | compression pairs |
| Exactness control | CORE | knows when exact wording is required | paraphrases source-critical text | definition/formula/quotation case |
| Lecture-cue detection | CORE | uses verbal signals to anticipate structure | reacts word-by-word | signposted lecture case |
| Format selection | CORE | picks outline/matrix/map/cues based on structure | one-template dogma | mixed lecture formats |
| Capture/revision separation | CORE | uses rough first pass then targeted revision | perfectionism during listening | live vs recorded case |
| Retrieval conversion | CORE | turns notes into recall prompts | passive rereading only | post-lesson review task |
| Coaching/scaffolding | CORE | teaches with prompts/drills and fades support | AI produces final notes immediately | novice coaching case |
| Metacognitive calibration | CORE | compares perceived understanding with recall evidence | neat notes mistaken for mastery | explain-without-notes test |
| Language/accessibility boundary | BOUNDARY-CRITICAL | adapts density/support without making diagnosis | penalizes learner for access need | constrained learner case |

## Critical competency -> evidence -> task -> verifier

1. Selection -> preserved core propositions with reduced nonessential text -> transform a verbose 90-second transcript -> proposition checklist + compression ratio.
2. Hierarchy -> correct parent/child and relation structure -> comparison/process lecture -> reference structure map.
3. Coaching -> learner performs cognitive work -> novice interaction -> check ratio of prompts/feedback to AI-produced final content.
4. Exactness -> source-critical wording preserved -> mixed exact/paraphrase case -> deterministic required-span check.
5. Retrieval -> questions target core meaning and learner can answer -> delayed review fixture -> answer-key coverage.
6. Progression -> next drill addresses dominant bottleneck -> longitudinal samples -> rubric on diagnosis-to-intervention fit.
