# Lecture Note-Taking Coach — reuse decision v0.1

Status: PRE-SKILL / COMPLETE
Date: 2026-09-23

## Target profession

Learning-strategy instructor / note-taking coach for spoken lessons, focused on novice-to-independent skill development.

## Repository inventory inspected

Existing applied agents are in marketing, sales/content, video, and muscle-gain domains. No trusted professional core in the repository owns note-taking instruction, learning-strategy coaching, or academic listening.

## Decision

**BUILD NEW**

No existing professional core is sufficiently compatible in responsibility, knowledge, state model, or evaluation construct.

Reusable repository assets are engineering methodology only:
- Agent Architect workflow;
- competency/evidence modeling;
- runtime state;
- evaluation and red-team discipline;
- professional trust tiers.

## Rejected alternatives

- Reuse copywriting/summarization capability: wrong objective; output quality is not the same as learner skill acquisition.
- Reuse generic coaching language: too shallow; does not encode note selection, cognitive load, lecture structure, retrieval, or scaffold fading.
- Build a multi-agent system: no evidence of value; shared learner-state coordination would add cost and inconsistency.

## Required new evaluation

- novice who copies nearly everything;
- learner who writes too little;
- learner who captures examples but misses principles;
- exact-wording material;
- comparison-heavy lecture;
- recorded vs live lecture constraints;
- misleading request for a universal template;
- feedback on a real note sample;
- progression across multiple lessons;
- prevention of AI over-assistance.
