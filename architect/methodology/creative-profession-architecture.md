# Creative Profession Architecture

Status: v0.1.

## Purpose

Prevent Agent Architect from turning creative work into a rigid checklist or mistaking reference imitation for taste.

Creative professions require the same evidence discipline as technical work, but the evidence target differs. In many creative tasks there is no single mechanically correct output. Quality emerges from constraint understanding, domain fundamentals, divergent exploration, contextual appropriateness, originality, execution quality, and expert critique.

## 1. Separate constraint types

Before modeling a creative role, distinguish:

- hard constraints: legal, technical, production, accessibility, brand, format, budget, deadline;
- communication/function constraints: message, audience, intended behavior, usability, hierarchy;
- contextual conventions: genre, market, cultural expectations, medium norms;
- aesthetic preferences: stakeholder or audience taste that may be negotiable;
- open creative space: dimensions where novelty and authorial judgment are desirable.

Do not convert soft preference into a universal rule. Do not ignore hard functional constraints in the name of originality.

## 2. Model creative competence as a system

For material creative roles map separately:

1. fundamentals/craft;
2. problem framing and brief interpretation;
3. reference literacy;
4. divergent exploration;
5. concept formation;
6. contextual judgment;
7. execution/craft control;
8. critique and revision;
9. production/release verification.

A role can be strong in one layer and weak in another. A polished artifact with a weak concept is not equivalent to a strong concept with incomplete execution.

## 3. Reference literacy is not imitation

References should be analyzed for underlying decisions rather than copied as surface style.

For each reference ask:

- What problem did it solve?
- Which constraints shaped it?
- Which compositional/typographic/material/interaction decisions carry the effect?
- Which parts are context-specific and non-transferable?
- What would become derivative if copied directly?
- Which principle can be abstracted safely?

Reference gathering must include enough breadth to avoid anchoring on one fashionable style.

## 4. Divergence before convergence

Creative exploration must include genuinely different solution families when the problem permits it.

Do not treat minor styling changes as alternatives.

A useful divergence check asks whether alternatives differ in one or more of:

- concept/metaphor;
- composition or spatial logic;
- information hierarchy;
- interaction model;
- tone/voice;
- material/visual language;
- medium/production technique;
- audience framing.

Convergence should occur only after alternatives are compared against the actual brief and intended effect.

## 5. Novelty and appropriateness

Originality alone is not sufficient. Familiarity alone is not sufficient.

Evaluate the relationship among:

- originality/novelty;
- appropriateness to the brief and audience;
- communicative/function effectiveness;
- craft/execution quality;
- coherence;
- distinctiveness relative to relevant references/competitors;
- risk introduced by rule-breaking.

The weighting depends on the profession and assignment. A safety-critical information graphic and an experimental poster should not be judged by the same balance.

## 6. Taste as calibrated domain judgment

Do not encode `taste` as unexplained preference.

Operationalize taste through observable behaviors:

- notices subtle hierarchy, rhythm, proportion, typography, imagery, pacing, or material problems;
- recognizes clichés and overused visual tropes;
- distinguishes intentional tension from accidental inconsistency;
- predicts which decisions will weaken the intended perception;
- can compare two plausible solutions and articulate why one better serves the brief;
- can identify when technically correct work still feels generic, derivative, incoherent, or overworked;
- can revise without merely adding decoration.

Taste remains partly tacit and domain-specific. It should therefore be trained/evaluated with curated comparative examples, critique tasks, authentic artifacts, and calibrated expert review rather than only prose rules.

## 7. Rule breaking

A creative agent may violate a conventional rule only when it can state:

`rule -> usual purpose -> why this context justifies violation -> intended effect -> downside/risk -> verification method`.

Unexplained nonconformity is not creativity.

## 8. Critique architecture

Critique should diagnose before prescribing.

Useful critique sequence:

1. restate intended effect and constraints;
2. observe the actual artifact rather than infer from source files/descriptions;
3. identify the strongest and weakest perceptual/functional decisions;
4. separate concept problems from execution problems;
5. identify likely root causes;
6. propose multiple repair directions when appropriate;
7. choose a direction based on the brief;
8. revise and re-observe.

Avoid generic critique such as `make it more premium`, `add visual interest`, `improve hierarchy`, or `make it pop` without causal diagnosis.

## 9. Evaluation of creative agents

Do not rely on a single deterministic rubric for irreducibly subjective dimensions.

Use a mixed evaluation design:

- deterministic checks for hard constraints and production correctness;
- comparative/pairwise assessment for competing artifacts;
- domain-expert judges for creativity/taste/contextual judgment;
- multiple independent judgments for high-subjectivity dimensions when practical;
- artifact-first review, preferably blind to generation method when possible;
- separate ratings for concept, appropriateness, originality, craft, and functional effectiveness;
- adversarial tests that tempt the agent toward fashionable imitation, over-decoration, safe generic work, or rigid rule following.

Calibrate AI/model graders against domain-expert judgments before relying on them for subjective creative quality.

## 10. Creative failure modes

Explicitly test for:

- reference copying / style mimicry without problem understanding;
- trend chasing;
- generic polished output;
- premature convergence on the first plausible direction;
- pseudo-divergence: several variants of the same idea;
- overformalization and checklist aesthetics;
- novelty that harms communication/function;
- excessive respect for the user's aesthetic premise;
- confusing stakeholder preference with professional evidence;
- critique based on adjectives rather than observable causes;
- polishing before concept validation;
- inability to inspect the actual rendered/produced artifact;
- inability to explain intentional rule breaking.

## Quality gate

A creative-profession architecture passes only if it can preserve open exploration while still providing disciplined selection, critique, verification, and evidence of professional judgment.
