## Decision

Reject the three static labels as the explanatory mechanism. The idea is one persistent object changing state under a visible cause, not a taxonomy of three tiers.

Selected representation: **one persistent stock body that depletes, with each fulfilled order visibly taking from it.** The stock object is on screen continuously from first frame to last; fulfillment events are the agent of change.

Assumptions stated and proceeding: the narrative is conceptual (no approved dataset, no approved thresholds); delivery is vertical mobile; the mechanism is open creative space; the structural edit is not yet confirmed locked.

## Diagnosis

"Full / Medium / Low" fails three ways at once:

1. **Process rendered as classification.** Three labels are three separate states with no causal agent between them. The viewer learns that categories exist, not that orders consume stock. The word "gradually" in the brief is exactly what discrete labels delete.
2. **Unsupported quantitative implication (MG-02 / MG3-08).** Three named tiers imply defined boundaries — where Full ends, where Low begins. We have no approved thresholds, so the geometry would assert measurement we cannot source.
3. **Generic default (MG3-01, MG3-08).** It is the numbered-card reflex in label form: dashboard chips standing in for explanation.

## Divergence considered

- **A. Persistent depleting body** — one stack/column of discrete units; each fulfilled order removes units. Preserves object identity, continuity and causality.
- **B. Transfer/migration** — units leave the stock region and travel out to fulfilled orders. Shows conservation: stock does not vanish, it goes somewhere.
- **C. Depleting body plus one threshold marker** — adds the consequence (you cross the reorder point unattended).

Selection: **A as the carrier, with B's transfer as the accent on each order event.** Depletion alone explains "it shrinks"; the outbound unit explains *why*. C is held in reserve — it only enters if the reorder point is a product-defined concept from the brief owner, never as an invented number or line position.

If the client requires the three words, they may survive only as passive zone annotations the single persistent object travels through — never as three separate cards, and never with numeric boundaries.

## Motion contract (MG3-09)

- Job: show depletion as continuous and caused by fulfillment, unattended by anyone.
- Represented change: stock quantity decreasing via discrete order events.
- Viewer inference: every order silently costs stock; nobody is watching the level.
- Timing/hold: order events land on narration beats, not on a uniform metronome; depletion eases, it does not scroll at constant speed; hold ~0.8-1.0s on the resolved low state before the cut.
- Removal criterion: if narration names a figure, or the form starts implying a measured rate, strip ticks/scale — or drop the element.

No axes, percentages, tick values, rates or timestamps.

## Actions

1. Author three styleframes before any animation: opening (full body, first order entering), peak (mid-depletion, transfer visible), resolved (low, nothing having intervened). Static hierarchy check against subject and captions.
2. Build one 2-3s motion prototype proving the depletion curve and a single order event (MG3-13). No full-length build before it passes.
3. Typography: one label role, single weight, sentence case, no outline/shadow/color patching (MG3-06).
4. Overlay ledger entries opened for the stock label and any zone words — each needs an approved source beat, time range and owner before render.
5. Runtime route (MG3-14): the unit/container must be authored vector form with deliberate proportion. If only CSS primitives are available, choose the honest simple form — a single body of discrete unit ticks — rather than letting it collapse into dashboard cards.
6. Route to brief owner: are Full/Medium/Low actual product-defined states in the interface? If yes they become approved semantics and the mechanism shifts to named zones on the persistent object — that changes this answer.
