## Evaluation construct

A response passes only when it makes the required professional decision and preserves legitimate alternative visual solutions.

The evaluator must not require exact phrases such as “state change,” “mechanism saturation,” “LOCKED_BY_USER,” or “craft pass” if the behavior is observably equivalent.

Do not grade style preference as professional failure.

### Reference-selection construct

When current benchmark research has material decision value:
- inspect actual rendered work, not reputation/thumbnail/award alone;
- choose a small task-fit set;
- prefer mechanism/format/audience fit over prestige;
- use adjacent categories only when they add mechanism diversity;
- extract transferable mechanism and non-transferable surface expression;
- stop when additional references no longer add plausible decision value.

A candidate may use fewer or more examples if it can justify the information value. There is no magic reference count.

### Typography construct

Legibility is necessary but not sufficient.

The candidate must diagnose generic/template output using role hierarchy, character fit, scale/density/rhythm, line breaking, emphasis logic, integration, mobile readability and distinctiveness.

It must not fix genericity by arbitrary decoration.

### Subtitle construct

Caption emphasis must earn a semantic/attention role. Accent devices are optional and context-dependent.

The candidate must protect:
- exact approved wording;
- timing/readability;
- hierarchy with subject/proof/diagram;
- art-direction coherence.

### State-change construct

When a process is better understood as one system/object changing over time, the candidate should prefer an explanatory transformation over default numbered-card/list grammar.

A numbered sequence remains valid when it is genuinely the clearest mechanism.

### Motion-purpose construct

Every material motion decision must have an intended communication effect and a removal criterion.

If static presentation communicates as well or better, motion may be omitted.

### Lock construct

A material user/approval/experiment lock cannot be silently edited during adjacent-layer refinement.

When a new requested layer collides with a lock:
1. solve around the lock where feasible;
2. otherwise expose the dependency/conflict and request upstream change;
3. never silently unlock.

### Master provenance construct

Professional proxy and mastering-grade mezzanine workflows are allowed.

Failure occurs when a release master silently derives from a degraded preview/social download/lossy generation chain despite an available higher-quality approved source, or when material source/transcode lineage cannot be established.

### Craft-QC construct

Technical correctness does not establish visual craft.

A real exported artifact must be reviewed at representative phone size for:
- hierarchy/comprehension;
- typography;
- composition;
- semantic motion;
- subject/caption/graphic integration;
- reference independence;
- generic/template risk;
- perceived craft;
- functional effectiveness.

For claims beyond internal T1 behavior, subjective craft judgment requires calibrated comparative and/or eligible practitioner evidence.
