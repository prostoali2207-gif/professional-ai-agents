# Motion Graphics & Visual Explanation — targeted evaluation plan v0.1

Status: PREREGISTRATION DRAFT — NOT YET SCORED  
Parent capability: `video-editing-post-production@0.1.0`

## Objective

Test only the new motion-graphics delta and its interactions with the qualified Video Editing & Post-Production parent.

Do not rerun the entire historical parent qualification without a coupling reason.

## Claims under test

- MG-C1: forms an explanatory visual mechanism instead of decorative labels.
- MG-C2: preserves information integrity and never fabricates quantitative chart meaning.
- MG-C3: controls hierarchy among subject, captions and graphics.
- MG-C4: preflights typography/localization and prevents missing-glyph release.
- MG-C5: uses authored motion timing/easing rather than mechanical UI movement.
- MG-C6: produces coherent explanatory diagrams/infographic animation.
- MG-C7: selects and executes appropriate compositing mode.
- MG-C8: resists single-reference/competitor surface imitation.
- MG-C9: routes work to an execution runtime capable of the chosen craft.
- MG-C10: critiques actual renders and classifies the responsible failure layer.

## Evaluation layers

### Layer A — deterministic contract/static checks

PASS requires:
- candidate marked NOT QUALIFIED;
- exact parent digest pinned;
- no claim of invented data;
- runtime limitation route exists;
- glyph/font preflight exists;
- artifact-first review required;
- BUILD NEW stop/reopen rule preserved.

### Layer B — semantic judgment fixtures

Families:
- `EXPLAIN`
- `DATA_TRUTH`
- `HIERARCHY`
- `TYPE`
- `MOTION`
- `COMPOSITE`
- `REFERENCE`
- `TOOL_ROUTE`
- `CRITIQUE`

P0 hard-fail families:
- DATA_TRUTH
- TYPE release failure
- REFERENCE direct imitation after explicit anti-imitation requirement
- false execution/readiness claim when renderer/artifact is unavailable

### Layer C — practical real-media gate

Use one real talking-head source with approved Russian speech.

Required authored visual explanations:
1. attention migration from an older project to a newer project;
2. investment lifecycle: entry -> hold -> exit;
3. restrained CTA resolution back to the speaker.

#### Practical protocol

1. Build semantic beat map.
2. Produce three materially different styleframe/mechanism directions for at least the attention-migration block.
3. Select one direction using explicit communication/craft reasoning.
4. Implement with a renderer that supports the selected motion mechanism.
5. Render the real clip.
6. Inspect at representative phone size.
7. Verify Cyrillic glyph coverage.
8. Verify captions and graphics do not compete materially.
9. Run affected Video Editing parent QC.
10. Collect independent perceptual judgments.

## Practical judge dimensions

Score separately:
- concept/explanatory value;
- hierarchy/comprehension;
- originality/reference independence;
- typography;
- motion timing/easing;
- compositing/integration;
- overall craft;
- functional effectiveness.

Do not collapse these into one scalar before diagnosis.

## Independent-judge requirement

For subjective craft:
- minimum three independent judgments where feasible;
- at least one judge path must be calibrated against strong motion-design examples or a human/domain-expert review process;
- user preference can be recorded but cannot be the only professional oracle.

A model-only judge that has not been calibrated may support diagnosis but cannot alone establish qualification.

## Parent interaction regressions

Required targeted checks:
- VE-02 pacing/comprehension;
- VE-07 text/captions/graphics;
- VE-08 effects/motion;
- VE-09 reproducibility/font/assets;
- VE-11 artifact-first QC;
- VE-12 revision/root-cause repair.

Run broader parent regression only if shared implementation changes those invariants.

## Hard fails

- fabricated measured chart/data;
- missing glyphs in release candidate;
- graphics materially obscure proof/face/CTA without justified purpose;
- direct competitor surface imitation after references should have been abstracted;
- renderer cannot execute the selected mechanism but candidate claims professional render success;
- technical QC pass reported as creative readiness without perceptual review;
- candidate claims QUALIFIED before practical gate and independent judgment requirements pass.

## Stop rule

If a second materially different real-media task shows that motion concept/taste/workflow cannot be owned coherently inside Video Post-Production, open an architecture review for BUILD NEW Motion Graphics core.

Do not split based on one difficult render alone.
