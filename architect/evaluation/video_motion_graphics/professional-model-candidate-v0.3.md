## MG3-01 Commercial visual-system art direction — CORE

Treat a motion piece as one designed system, not a sequence of individually clean overlays.

Control and critique:
- scene-to-scene visual coherence;
- composition, grid, proportion, spacing and negative space;
- scale relationships;
- typography as designed form;
- shape/path/iconographic language;
- color/value/contrast relationships;
- depth/material/texture/blur/light when appropriate;
- density/restraint;
- continuity between subject, captions, diagrams and CTA.

A technically clear piece can still fail when it reads as generic presentation UI, dashboard cards, app components or an obvious template without a brief-driven reason.

Do not use “premium” or “high-end” as diagnosis. Name observable causes.

### Failure: GENERIC_VISUAL_SYSTEM
Repair the system—composition, type, motif, spacing, graphic language—rather than hiding genericity under effects.

## MG3-02 Comparative craft judgment — CORE

When two or more plausible directions exist, compare them against the same brief.

Evaluate separately:
- communication effectiveness;
- visual-system coherence;
- composition/proportion/spacing;
- typography craft;
- graphic-language craft;
- motion timing/curve quality;
- integration/depth;
- authored distinctiveness;
- restraint/complexity appropriateness;
- mobile final impression.

Distinguish:
- intentional restraint from under-design;
- surface polish from authored distinctiveness;
- sophistication from over-decoration.

Preserve legitimate alternatives. Do not turn taste into a single unexplained scalar.

## MG3-03 Structural edit lock before motion — BOUNDARY-CRITICAL

Required sequence:

`source -> semantic beat map -> ROUGH/STRUCTURAL EDIT LOCK -> motion opportunity map -> divergence -> styleframes -> motion prototype -> integrated render -> QC`

Do not fully author expensive motion while VE-02/VE-03 structure remains materially unstable.

Bounded exploratory styleframes/prototypes are allowed when they reduce uncertainty without creating false sunk-cost pressure.

If a material structural edit changes after timing is authored:
- invalidate affected timing/compositing assumptions;
- re-integrate;
- rerun affected checks.

### Failure: PREMATURE_MOTION_POLISH

## MG3-04 Semantic overlay ledger — BOUNDARY-CRITICAL

Before render, maintain a compact ledger for every material overlay:

`overlay text -> approved semantic statement/source beat -> time range -> owner/evidence`

Every material overlay must map to approved meaning.

A beautiful overlay that contradicts narration/brief is a composed-system failure even if typography and animation are flawless.

No release-ready status until contradictory or unsupported overlays are repaired and re-observed.

## MG3-05 Fit-for-purpose benchmark selection — CORE

Research current references when they can materially change a visual decision.

Build a small decision-useful set:
- inspect actual rendered artifacts when available;
- prioritize task/format/audience/mechanism fit over fame, awards or prestige;
- use adjacent-category references only when they add mechanism diversity;
- extract:
  `problem -> mechanism -> why it works -> transferable principle -> non-transferable surface expression -> derivative risk`;
- stop when new examples repeat existing mechanisms and have low plausible decision value.

References calibrate mechanism and craft. They never become the default surface template.

When current visual practice matters, retrieve live evidence rather than relying on stale memory.

## MG3-06 Authored typography — CORE

Legibility is necessary but not sufficient.

For material titles, labels and motion typography, evaluate:
- role hierarchy;
- type character/context fit;
- scale and density;
- line breaks/grouping;
- emphasis logic;
- spatial integration;
- temporal rhythm;
- mobile readability;
- default/template risk.

Do not “repair” generic typography by automatically adding color, italic, outline, shadow or a fashionable font.

### Failure: GENERIC_TEMPLATE_TYPOGRAPHY

## MG3-07 Semantic caption emphasis — BOUNDARY-CRITICAL

Parent VE-07 retains wording, timing, readability and truth boundaries.

When enhanced caption treatment is authored here, every accent must have a semantic/attention function.

Eligible devices may include weight, scale, slant, color, position, timing, mask or bounded kinetic emphasis. None is mandatory.

Protect hierarchy with subject, proof and diagrams. Repeated accent that makes everything loud is a failure.

Locked caption layers remain immutable for the current revision.

## MG3-08 State-change explanation — CORE

Before defaulting to cards or `01 -> 02 -> 03`, test whether the idea is better understood as:
- one persistent object changing state;
- one object moving through states;
- a relationship changing;
- transfer/migration;
- accumulation/depletion;
- one record/system gaining or losing attributes.

Select the representation that best preserves identity, causality, sequence or relationship.

Numbered steps remain valid when genuinely clearest.

Do not imply measured magnitude, rates or timestamps without approved evidence.

## MG3-09 Motion information gain — CORE

For each material animated element define internally:

`communication job -> represented change -> intended viewer inference -> timing/hold -> removal criterion`

Eligible jobs include attention direction, causal/temporal explanation, continuity, process compression, deliberate emotional/brand beat.

“Dynamic,” “premium,” “competitors do it,” or “the renderer can do it” is not sufficient.

If static treatment communicates as well or better, reduce or omit motion.

Judge combined attention load, not each effect in isolation.

## MG3-10 Revision locks — BOUNDARY-CRITICAL

Track material layers:
- `UNLOCKED`
- `LOCKED_BY_USER`
- `LOCKED_BY_APPROVAL`

## MG3-12 Technical QC vs craft QC — CORE

Maintain separate states:

`TECHNICAL_PASS | TECHNICAL_FAIL`

`CRAFT_PASS | CRAFT_FAIL | CRAFT_NOT_OBSERVED`

Technical pass may cover decode, dimensions, streams, glyphs, safe placement and audio validity.

Craft requires observation of the exported artifact at representative phone size.

Judge:
- visual-system coherence;
- composition/proportion/spacing;
- typography;
- graphic language;
- motion timing/curves;
- scene continuity;
- compositing/depth;
- authored distinctiveness vs generic/template look;
- restraint;
- functional effectiveness.

A technically valid but generic, cluttered, mechanically animated or poorly integrated render is `CRAFT_FAIL`.

For strong professional-craft claims, use calibrated comparative and/or eligible practitioner evidence. Uncalibrated model-only taste cannot establish qualification.

## MG3-13 Styleframe and motion-language prototype gate — CORE

Before full-length motion implementation for a selected direction:
- inspect opening state;
- inspect peak explanatory state;
- inspect resolved state;
- inspect one short animated prototype demonstrating the actual motion language.

Reject/repair before full render if the system already reads as generic presentation UI, weak typography, incoherent graphic language or unjustified complexity.

## MG3-14 Runtime and asset-authoring route — CORE

Separate:
- renderer capability;
- asset-authoring capability;
- professional craft.

A renderer such as Remotion may be technically eligible without being sufficient to author every selected visual direction.

If the direction requires unavailable custom vector/image/3D/texture asset craft:
- route to an eligible authoring capability; or
- deliberately choose a simpler direction that still meets the brief.

Never silently downgrade intended craft into generic CSS/cards because implementation is convenient.

## Ready-state gate

No `PRACTICAL_PASS_CANDIDATE` unless:
- structural edit was locked before full motion;
- selected direction survived styleframe/prototype review;
- overlay ledger is clean;
- source/master lineage is known;
- renderer/asset-authoring route was sufficient;
- exported artifact was decoded;
- typography/glyph requirements pass;
- technical QC is complete;
- craft was observed at phone size;
- affected parent checks are complete.
