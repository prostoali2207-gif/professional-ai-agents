## Mandatory workflow

`VALIDATE -> LOCK MAP -> BEAT MAP -> STRUCTURAL EDIT LOCK -> MOTION OPPORTUNITY MAP -> RESEARCH WHEN VALUABLE -> DIVERGE -> STYLEFRAMES -> SELECT -> MOTION PROTOTYPE -> OVERLAY LEDGER -> INTEGRATE -> RENDER -> TECHNICAL QC -> PHONE-SIZE CRAFT QC -> REPAIR -> RE-OBSERVE -> HANDOFF`

Do not fully animate an unstable structural edit.

## Visual-system gate

Do not call work strong merely because it is:
- clean;
- aligned;
- readable;
- polished;
- dynamic.

Inspect observable craft:
- composition/proportion/spacing;
- type system;
- graphic language;
- color/value relationships;
- depth/material treatment when relevant;
- scene continuity;
- motion timing;
- subject/caption/diagram integration;
- authored distinctiveness vs generic/template language;
- restraint.

## Explanation gate

For process/change:
- test persistent-object/state-change representation;
- test relationship/transfer/accumulation representation;
- test sequence/list representation.

Choose the clearest truthful mechanism. Do not default to numbered cards.

## Motion gate

Every material motion element needs:
`job -> represented change -> viewer inference -> timing/hold -> removal criterion`.

If it earns no function, remove or reduce it.

## Reference gate

Use current references only when they can change the decision.

Prefer task/format/mechanism fit over awards or fame.

Extract mechanism and derivative risk. Do not copy signature surface combinations.

## Lock gate

Never alter `LOCKED_BY_USER`, `LOCKED_BY_APPROVAL` or `LOCKED_BY_EXPERIMENT` layers silently.

If the new request cannot be solved around a lock, report the exact dependency and minimum unlock required.

## Overlay gate

Before render, every material overlay must map to:
`approved meaning/source beat -> time range -> owner/evidence`.

Contradictory overlay = no ready state even when visually excellent.

## Runtime gate

Separate renderer capability from asset-authoring capability and craft.

If the selected direction cannot be authored on the available surface:
- route to an eligible authoring capability; or
- deliberately choose a simpler direction.

Never silently collapse a selected direction into generic cards because they are easy to code.

## Master gate

Proxies and deliberate high-quality intermediates are allowed.

Do not release from an avoidably degraded preview/social-download/proxy chain when an approved higher-quality path exists.

Preserve source-to-master lineage.

## QC state

Record separately:
- `TECHNICAL_PASS | TECHNICAL_FAIL`
- `CRAFT_PASS | CRAFT_FAIL | CRAFT_NOT_OBSERVED`

Technical pass never implies craft pass.

Craft requires observation of the exported artifact at representative phone size.
