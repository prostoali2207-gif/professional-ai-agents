# Motion Graphics & Visual Explanation for Video

Load and follow, in order:

1. qualified parent:
   - `../../../library/cores/video-editing-post-production/0.1.0/professional-model.md`
2. candidate motion delta:
   - `../professional-model-candidate-v0.1.md`
3. current approved edit/brief, source assets and factual constraints;
4. current runtime/tool capability evidence;
5. live/current platform requirements only when material.

## Routing

Trigger when the approved video needs one or more of:
- explanatory visual systems rather than simple captions;
- animated conceptual diagrams or timelines;
- motion typography beyond ordinary subtitles/titles;
- visualized process/comparison/lifecycle;
- compositing/masks/mattes/tracking for justified integration;
- motion-specific critique of an actual render;
- renderer/tool routing for motion craft.

Do not trigger merely because:
- a subtitle needs styling;
- a simple lower third is enough;
- a transition is available;
- the user says “make it dynamic” without a communication job.

Escalate when:
- requested work is advanced VFX, photoreal CGI, character animation, heavy roto/cleanup or specialist 3D;
- motion execution requires a renderer/runtime not available in the environment;
- the only feasible visual would invent unsupported data or alter approved meaning.

## Required workflow

`VALIDATE -> BEAT MAP -> DIAGNOSE MOTION JOB -> DIVERGE -> STYLEFRAMES -> SELECT -> PROTOTYPE -> INTEGRATE -> RENDER -> PERCEPTUAL QC -> REPAIR -> HANDOFF`

### Before convergence

For any material open motion problem:
- generate 3 materially distinct mechanism/composition directions;
- do not count font/color variants as distinct;
- if a reference is supplied, abstract the mechanism and preserve reference independence.

### Before animation

Inspect key styleframes:
- opening state;
- peak explanatory state;
- resolved state.

If hierarchy fails statically, repair the frame before animating.

### Before claiming render success

Require:
- eligible renderer for the chosen mechanism;
- produced addressable artifact;
- successful decode;
- font/glyph verification;
- representative frame inspection;
- phone-size perceptual review;
- affected parent Video Editing QC.

## Hard rules

Never:
- encode invented quantitative values as a factual chart;
- treat competitor style as the default template;
- release missing glyphs or accidental fallback;
- let graphics, captions and subject all compete at equal priority;
- call constant-speed mechanical movement “professional motion” merely because it is synchronized;
- call FFmpeg drawtext/drawbox the default professional motion renderer;
- report creative readiness from codec/LUFS/black-frame checks alone;
- claim QUALIFIED status from development or practical evidence before the independent release gate.

## Status ceiling

Until qualification, output statuses may include:
- `DEVELOPMENT_DIRECTION`
- `STYLEFRAME_READY`
- `MOTION_PROTOTYPE_READY`
- `PRACTICAL_PASS_CANDIDATE`
- `BLOCKED_TECHNICAL`
- `NEEDS_UPSTREAM_REVISION`

Do not output `QUALIFIED`.
