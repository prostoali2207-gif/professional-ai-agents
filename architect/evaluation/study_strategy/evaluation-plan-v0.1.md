# Study Strategy — evaluation plan v0.1

Status: PRE-SKILL PLAN
Date: 2026-10-28

## Claim boundary

Candidate claim: the capability can convert lesson/source material into a bounded durable-study plan by selecting memory targets, matching practice to target type, using retrieval + correction + distributed review, and requiring delayed evidence before calling knowledge retained.

It does not claim:
- one universal review timetable;
- authority over religious/domain importance;
- clinical memory optimization;
- T1/T2/T3 qualification.

## Critical claims

### SS-C1 — Selective memory investment
The skill does not turn every note into active memorization.

Hard fail: indiscriminate flashcardization or "memorize everything."

### SS-C2 — Endpoint classification
The skill distinguishes reference-only, understanding, recall, exact, discrimination, application and evidence-chain targets where relevant.

Hard fail: every target gets the same study method.

### SS-C3 — Retrieval matched to target
Recall goals use active retrieval; conceptual/application goals use explanation/discrimination/application where appropriate.

Hard fail: recognition-only practice is treated as durable recall mastery.

### SS-C4 — Corrective relearning
Failed or distorted retrieval is checked against the source/domain authority and corrected before continued rehearsal.

Hard fail: incorrect wording/attribution is repeatedly practiced.

### SS-C5 — Adaptive spacing
The skill rejects a universal fixed interval schedule and adjusts review from retention horizon + observed performance + review load.

Hard fail: claims `1-3-7-30` or another sequence is universally optimal.

### SS-C6 — Delayed evidence
One immediate correct answer does not establish durable retention.

Hard fail: same-session familiarity/recognition = "mastered."

### SS-C7 — Review-load control
The system can prune/merge/downgrade low-value targets.

Hard fail: backlog grows without prioritization or retirement logic.

### SS-C8 — Domain fidelity
Exact/source-critical targets require verified authoritative wording and preserve material conditions/attribution.

Hard fail: paraphrase is converted into exact quotation target.

### SS-C9 — Islamic authority boundary
The skill may recommend study priority but may not invent a religious obligation to memorize or silently elevate teacher explanation to revelation/scholar consensus.

### SS-C10 — Composition
Learning-coach owns teaching/fading; note-taking owns representation; study-strategy owns durable retention decisions.

## Evaluation families

1. mixed lesson with core points, examples, repetition and reference details;
2. user asks to memorize everything;
3. user requests fixed "best" spaced schedule;
4. exact quotation candidate with uncertain wording;
5. conceptual principle requiring explanation not verbatim memory;
6. similar concepts requiring discrimination;
7. rule requiring application to a case;
8. failed recall with confident wrong answer;
9. same-session success followed by delayed failure;
10. excessive review queue with limited daily time;
11. Islamic lesson with Qur'an/hadith/scholar/teacher/learner layers;
12. khilaf/conditions/attributed preference;
13. composition with note-taking + learning-coach.

## Evidence/grading

Deterministic checks where possible:
- target type present;
- exact-source target gated on verification;
- no universal fixed schedule claim;
- delayed check required;
- source layers preserved;
- low-value item not forced into active review.

Judgment-heavy target selection and review-load trade-offs require independent semantic/practitioner review for T1.

## Release status

Author-side static/development checks support project-use candidate status only.
T1 requires independent held-out practical evaluation.
