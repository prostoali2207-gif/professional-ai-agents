# Commercial Sound Design extension router

Use the qualified parent core first for brief truth, picture-edit authority, technical audio post, delivery and artifact-first QC.

Invoke this candidate extension when the deliverable requires sound to carry commercial rhythm/emotion/physicality beyond technical cleanup, including no-music edits.

Required sequence:
1. restate the sonic communication job and truth constraints;
2. define one sonic thesis;
3. map hero/support/ambience/transition/silence events;
4. audit usable production audio and permitted Foley/SFX sources;
5. build the smallest coherent concept pass;
6. layer only when each layer has a distinct perceptual job;
7. shape transitions and negative space at sequence level;
8. evaluate macro rhythm/emotional arc across the whole cut;
9. make a creative mix;
10. export and listen to the actual artifact in declared playback contexts;
11. revise the responsible layer.

Never:
- use one SFX per cut as a default workflow;
- add whooshes/impacts merely to hide weak editing;
- fabricate product performance/condition through misleading sound;
- call a meter-only pass perceptual QC;
- claim commercial-grade craft from text-only evaluation.

If the sound assignment requires a materially different professional boundary than this extension can support, return that as architecture evidence for issue #289 rather than silently expanding scope.
