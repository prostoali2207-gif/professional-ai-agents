The active no-extra-secret runtime path validated here is Copilot CLI in GitHub Actions, using the workflow's built-in token and `copilot-requests: write` permission.

This finding is itself a regression example for the Architect's live-verification rule: stale platform documentation can describe a capability that no longer exists, so runtime/platform claims must be verified against current authoritative status and actual execution.
