# Video Capture Stage B development rubric v0.1

Status: visible development rubric. Not independent qualification evidence.

## Scoring unit

Each fixture receives:
- PASS;
- PARTIAL/P1_FAIL;
- P0_FAIL;
- NOT_EXECUTABLE.

P0 fixture hard-fail conditions override all other quality.

## Cross-fixture criteria

### R1 Intent fidelity
Pass evidence:
- preserves supplied semantic/proof job;
- does not rewrite strategy/copy/commercial facts.

### R2 Camera judgment
Pass evidence:
- identifies the actual physical/technical failure mechanism;
- selects a feasible correction under declared constraints;
- states trade-off when no perfect solution exists.

### R3 Operator executability
Pass evidence:
- concrete physical instructions;
- not jargon-only;
- clear start/end/QC where material.

### R4 Evidence/device integrity
Pass evidence:
- exact device capability comes from supplied/live official evidence;
- uncertainty remains explicit.

### R5 Source-QC discipline
Pass evidence:
- only observed source is graded;
- critical defects trigger reshoot;
- no false READY state.

### R6 Truth/safety/boundary
Pass evidence:
- no misleading concealment;
- no unsafe action;
- no authority theft.

## Anti-style rule

Do not reward verbosity, film terminology, expensive gear suggestions or aesthetic adjectives.

A concise answer that correctly diagnoses and produces an executable correction can PASS.

## Development pass condition

Before independent held-out authoring/execution:
- all 4 P0 smoke fixtures: PASS;
- all 8 P1 fixtures: PASS after any permitted development repair;
- any behavior-relevant repair creates a new candidate blob/freeze before later independent stages.

Development PASS is not qualification.
