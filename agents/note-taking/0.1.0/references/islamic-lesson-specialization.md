# Islamic lesson note-taking specialization

Use whenever the material is Islamic knowledge: Qur'an/tafsir, hadith, fiqh, 'aqidah, seerah, usul, Arabic-Islamic terminology, or a scholar/teacher's lesson.

This is a **fidelity specialization**, not a page template.

## Governing principle

`COMPRESS WITHOUT LOSING MEANING, SOURCE, AUTHORITY LEVEL, CONDITIONS, OR MATERIAL DISAGREEMENT`

A concise note is bad if it changes who said what or turns uncertainty into certainty.

## Source layers

Where material, distinguish:

- `Q` — Qur'an;
- `H` — hadith / Prophetic report;
- `Ath` — athar / statement of salaf;
- `U` — named scholar / scholarly view;
- `T` — teacher's explanation;
- `Me` — learner's own inference/reflection;
- `?` — attribution/wording/reference requires verification.

Symbols are optional. The distinction is mandatory when confusion would change authority or meaning.

## Exact quotation boundary

Do not reconstruct Qur'an, hadith, or a scholar's quotation from uncertain memory and present it as exact.

If exactness is uncertain:
- record the meaning as a paraphrase;
- mark `?` / verify;
- verify before sharing/teaching if material.

## Mas'alah structure

When useful, preserve:

`MAS'ALAH -> RULING/CLAIM -> DALIL -> HOW DALIL SUPPORTS CLAIM -> CONDITION/EXCEPTION -> KHILAF -> TARJIH (attributed)`

Do not force this chain when the lesson is not structured that way.

## Disagreement

If material khilaf is taught:
- preserve each view sufficiently to distinguish it;
- preserve attribution when provided;
- preserve the teacher/scholar's preference as **their attributed tarjih**;
- do not convert one preference into ijma' or an unattributed universal ruling.

## Anti-verbatim order

When reducing overwriting, remove first:
1. rhetorical repetition;
2. duplicate examples;
3. long teacher phrasing;
4. obvious transitions;
5. repeated restatement.

Preserve when material:
1. source identity;
2. mas'alah;
3. ruling/claim;
4. conditions/exceptions;
5. dalil;
6. attribution;
7. material disagreement;
8. reasoning connecting evidence to the claim.

## Revision check

Ask:
1. Can I tell whether each important claim is Qur'an, hadith, scholar, teacher, or my own understanding?
2. Did I turn any paraphrase into a quote?
3. Are material references/attributions verified or visibly marked uncertain?
4. Did I preserve conditions/exceptions?
5. If disagreement exists, can I reconstruct the views and attributed preference?
6. Did I add something not actually in the lesson?

## Sharing boundary

Private rough notes may contain uncertainty markers.

Before teaching, posting, or sharing attributed religious content:
- verify material quotations/references when possible;
- preserve uncertainty if not verified;
- distinguish quotation from paraphrase;
- do not manufacture authenticity grades, consensus, attribution, or tarjih.
