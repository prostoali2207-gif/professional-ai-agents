# Note-taking method routing

Choose representation from information structure and use-case, not fashion.

## Outline

Use when:
- material is hierarchical;
- lecturer uses headings/subheadings;
- argument has reasons/support;
- sequence is mostly linear.

Pattern:
`Heading -> core point -> support/example`

## Matrix / table

Use when multiple items are repeatedly compared across the same dimensions.

Good:
`Concept | definition | condition | effect | example`

Do not force a table if dimensions are unstable or false symmetry would be created.

## Process / decision flow

Use when:
- procedure;
- chronology with dependencies;
- conditions/branches;
- troubleshooting or decision logic.

Capture:
`trigger -> step -> condition -> next -> exception`

## Concept map

Use when relationships matter more than order:
- cause/effect;
- part/whole;
- dependency;
- category/subcategory.

Keep it sparse. Decorative density is not learning value.

## Cornell-style container

Useful when a cue/question column supports later retrieval.

Treat Cornell as a page container, not a superior universal cognitive method.

## Hybrid

Use when the material genuinely mixes structures.

Example:
- outline for main argument;
- small matrix for one comparison;
- decision flow for one procedure.

## Compression primitives

Prefer:
- nouns/verbs/conditions over full grammar;
- indentation for hierarchy;
- arrows for directional relations;
- stable abbreviations;
- one concept per compact unit where practical.

Never shorten beyond reconstructability.

## Exactness routing

Prefer EXACT for:
- formal definition;
- formula;
- theorem/rule;
- quotation;
- source-critical proof/reference;
- named condition/exception;
- critical number/date.

Prefer PARAPHRASE for:
- explanation;
- repetition;
- illustrative example;
- rhetorical transition.

When uncertain, mark for verification rather than fabricate exactness.

## Example preservation

Keep an example when it:
- is the only thing making an abstract rule understandable;
- demonstrates an exception/boundary;
- is likely to be assessed/used later;
- contains unique evidence.

Otherwise compress or omit repeated examples.

## Live vs recorded

### Live
Optimize continuity. Missing-content marker beats losing the next minute.

### Recorded
Pausing/replay may improve fidelity, but the workflow should still preserve selection rather than become transcription unless documentation is the actual goal.
