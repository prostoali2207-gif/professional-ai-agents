# Note-taking methods and routing

No method is universally best. Route by information structure and learning task.

## Outline

Use for:
- hierarchy;
- lecture with clear headings/subheadings;
- arguments with supporting reasons;
- chronological explanation.

Pattern:
`Heading -> core point -> support/example`

## Matrix / table

Use when the lecture repeatedly compares the same dimensions.

Example columns:
`Concept | Definition | Cause | Effect | Example | Exception`

Do not use a table when categories are not stable; it can force false symmetry.

## Process / decision flow

Use for:
- procedures;
- algorithms;
- sequences;
- conditions and branches.

Capture:
`trigger -> step -> condition -> next step -> exception`

## Concept map

Use when relationships matter more than sequence:
- cause/effect;
- part/whole;
- category/subcategory;
- dependencies.

Keep it sparse. A dense decorative map is not automatically useful.

## Cornell-style container

Useful when the learner wants:
- main notes;
- cue/questions;
- short summary.

Treat it as a page layout, not a superior cognitive method. The value comes from selection, organization, cue generation and retrieval.

## Compression primitives

Prefer:
- remove articles/filler words;
- use noun + verb + condition/result;
- arrows for causal/directional relations;
- indentation for hierarchy;
- stable abbreviations;
- symbols only if decodeable.

Example:
"Because repeated retrieval strengthens access to learned information, practice testing is often more effective than rereading."
-> `retrieval practice -> stronger access/retention; often > rereading`

## Exactness rules

Prefer EXACT for:
- formal definition;
- formula;
- theorem/rule;
- named condition/exception;
- quotation;
- source-critical textual proof;
- exact number/date when material.

Prefer PARAPHRASE for:
- explanation;
- repeated restatement;
- illustrative example;
- rhetorical transition.

When uncertain, mark exact-source candidates during capture and verify in revision.

## Lecturer cues

Structural cues:
- "first/second/third";
- "the main point";
- "there are two reasons";
- "in contrast";
- "therefore";
- "the exception";
- "remember";
- "definition";
- "for example";
- "to summarize".

Coach the learner to react to the cue's function, not merely copy the cue words.

## Minimal symbol set

Start small:
- `->` leads to / causes;
- `<->` relationship;
- `vs` contrast;
- `+` plus/advantage;
- `-` minus/disadvantage;
- `!` important;
- `?` unclear/check;
- `Ex:` example;
- `Def:` definition.

Do not build a huge private shorthand dictionary before the learner can reliably use a small one.
