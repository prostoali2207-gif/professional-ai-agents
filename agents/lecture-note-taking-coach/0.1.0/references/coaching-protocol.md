# Coaching protocol

Use this module when teaching, diagnosing samples, or choosing the next drill.

## Default coaching loop

`SAMPLE -> DIAGNOSE -> ONE TARGET -> MODEL A SMALL FRAGMENT -> PRACTICE -> FEEDBACK -> RETRIEVE -> UPDATE STATE`

### 1. Sample
Prefer 5-20 lines of the learner's real notes plus the matching lesson fragment/transcript when available. If no sample exists, create a 60-120 second baseline drill from user-provided lesson material.

### 2. Diagnose
Classify the dominant bottleneck:
- VERBATIM_LOCK;
- UNDER_CAPTURE;
- FLAT_STRUCTURE;
- EXAMPLE_OVERLOAD;
- MISSING_RELATIONS;
- OVERCOMPRESSION;
- EXACTNESS_ERROR;
- DECODEABILITY_ERROR;
- REVIEW_FAILURE;
- FALSE_MASTERY;
- TOOL_DEPENDENCE.

Pick the bottleneck that most limits learning now. Do not list every minor flaw.

### 3. One target
Give one transferable rule. Examples:
- "Write the change in meaning, not the whole sentence."
- "One concept = one compact line; examples indent beneath it."
- "If the lecturer says 'three reasons', stop writing prose and make three slots."
- "Exact wording only for definitions/rules/quotations; paraphrase explanation."

### 4. Model only enough
Show 2-4 transformed fragments, not the whole lesson, unless a reference solution is explicitly needed after the learner attempts the task.

### 5. Practice
Use a short drill:
- identify core vs support;
- compress 3 sentences into 1 line;
- turn a paragraph into heading + 2 bullets;
- build a comparison table;
- mark exact-text spans;
- listen 60-90 seconds without pausing and capture structure;
- revise rough notes into retrieval cues.

### 6. Feedback
Use:
- KEEP — what worked;
- FIX — one priority error;
- RULE — the reusable rule;
- NEXT — the next tiny drill.

### 7. Retrieval
After revision, hide notes and ask 2-5 questions that test the main relationships/ideas. If recall fails, do not call the notes successful merely because they are concise.

## Scaffold fading

Stage A: coach labels information roles.
Stage B: learner labels; coach corrects.
Stage C: learner compresses; coach gives targeted feedback.
Stage D: learner chooses structure/format.
Stage E: learner self-critiques before coach review.
Stage F: coach only audits difficult cases.

Do not advance by calendar. Advance when the learner can perform the current behavior reliably.

## Recorded lessons

Early training may use pauses, rewinds, and transcript checks. Gradually:
1. cap pause frequency;
2. delay transcript checking until after capture;
3. require an uninterrupted segment;
4. retain transcript only as post-hoc fidelity check.

## Live lessons

Prioritize continuity:
- heading;
- core proposition;
- relation;
- critical exact item;
- uncertainty marker.

If something is missed, write `...` or `?` and continue. Do not sacrifice the next minute to recover one sentence.

## Progress signals

Positive:
- core proposition coverage preserved;
- less redundant wording;
- hierarchy clearer;
- learner can decode notes after delay;
- recall improves;
- fewer prompts needed.

Negative:
- notes shorter but explanations become vague;
- abbreviations cannot be decoded;
- main ideas disappear;
- learner waits for AI reconstruction;
- exact definitions become approximate.
