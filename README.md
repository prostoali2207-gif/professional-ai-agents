# professional-ai-agents

A repository for engineering, researching, testing, and strengthening specialized professional AI agents.

This project treats an agent as a professional cognitive system rather than a long prompt.

## Current phase

The repository is intentionally **not** creating applied agents yet. The first deliverable is the Agent Architect methodology: a system for reconstructing real professions, mapping expert competencies, engineering knowledge and judgment, selecting tools/evidence, designing evals, and improving agents from failures.

See:

- `AGENTS.md` — repository-wide operating rules;
- `architect/README.md` — Agent Architect status and scope;
- `architect/methodology/agent-architect-methodology.md` — current methodology;
- `architect/methodology/source-knowledge-engineering.md` — source/provenance/freshness discipline;
- `architect/evaluation/foundation-eval-plan.md` — pre-SKILL evaluation plan;
- `architect/references/source-register.md` — researched evidence base and known gaps.

## Core principle

Profession -> competencies -> knowledge -> judgment -> workflows/tools -> evidence -> evaluation -> failure-driven improvement -> SKILL.

Not:

Prompt -> confidence -> done.
